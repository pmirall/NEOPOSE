    Cómo se usa

    Posar

    • Modo IK: arrastra los puntos ● para llevar manos y pies; el ● mueve todo el cuerpo.
    • Modo FK (botón arriba a la derecha o tecla I): arrastra cualquier articulación ◉ y solo gira el hueso que la sostiene.
    • Toca cualquier pieza del cuerpo para girarla con el aro o con los deslizadores.
    • Toca la mandíbula o una oreja de un anthro para moverlas a mano.
    • Avatares (Cuerpo → Avatar importado): suelta un VRM, GLB o FBX humanoide sobre el lienzo, o elige uno libre de la galería. Se posa igual que el maniquí.
    • Arrastra el fondo para girar la cámara, rueda para acercar, botón derecho para desplazar.
